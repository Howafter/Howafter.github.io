由于我的Python环境运行报错，怎么也解决不了。所以准备壮士断腕，直接卸载所有环境并进行重装！！！

卸载：Python → PyCharm → Anaconda（可选）

🧹 一、卸载 Python 环境

  1. 卸载 Python 本体

方法一：通过“应用和功能”卸载
打开 设置 → 应用 → 应用和功能。
找到所有名为 Python x.x.x（如 Python 3.11.5） 的条目。
点击 → 卸载。

方法二：使用控制面板卸载
控制面板 → 卸载程序 → 找到 Python。
卸载所有安装的版本（可能有多个）。

🧹 二、卸载 PyCharm

方法一：通过 JetBrains Toolbox

如果你是通过 JetBrains Toolbox 安装 PyCharm：

打开 Toolbox，点击 PyCharm 后的齿轮图标。
选择 Uninstall。

方法二：手动卸载

设置 → 应用 → 应用和功能 → 找到 PyCharm Community 或 PyCharm Professional
点击 → 卸载。

#define的各种用法

在 C 语言中，#define 预处理指令最基本的作用是进行文本替换（常说的“等价于”）。但实际上，它的功能远不止于此。通过结合各种语法特性，#define 可以变得非常灵活和强大。下面我将系统地介绍 #define 的各种用法，重点突出“除了简单替换”以外的功能。

7. 预定义宏

编译器提供了一些预定义的宏，用于获取编译信息：

  • __LINE__：当前行号
  • __FILE__：当前文件名
  • __DATE__：编译日期
  • __TIME__：编译时间
  • __func__：当前函数名（C99）
  • __cplusplus：C++ 编译时定义
  • __STDC__：表示遵循 ANSI C

9. 宏的副作用与注意事项

  • 宏参数可能被多次求值（例如 MAX(++x, y) 中 ++x 可能执行两次）。
  • 宏不进行类型检查。
  • 宏展开后可能产生意想不到的结果，比如运算符优先级问题，所以通常需要加括号。
  • 宏定义的常量无法被调试器看到（在预处理阶段已替换），而 enum 和 const 变量则保留符号。

11. 宏与 #undef

可以用 #undef 取消之前定义的宏，便于重新定义或限制作用域。

12. 宏的递归与重入

宏定义不能直接递归，但可以通过间接方式实现有限递归（如利用多个宏互相调用）。但一般不建议，容易混乱。

总结

#define 远不止“等价于”那么简单，它提供了文本替换、参数化、字符串化、标记粘贴、可变参数、条件编译等一系列强大功能。合理使用宏可以提高代码的灵活性和可维护性，但也需谨慎避免副作用和可读性问题。理解这些用法，能让你更好地阅读和编写 C/C++ 代码。

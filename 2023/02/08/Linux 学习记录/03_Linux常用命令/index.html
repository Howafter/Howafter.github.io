Linux常用命令

Linux常用命令

很多小伙伴对Linux的印象，就是黑色的命令行框框，虽然我们使用的Ubuntu系统给我们提供的图形化的交互界面，但课程中我们尽可能减少使用，因为在开发过程中命令行的方式效率是会更加高的，后期我们在写一些自动化脚本时，用的也都是命令行，可能一开始学习时，你对命令不熟悉，感觉效率还不如鼠标点点点。但是相信我，在你熟悉命令后，开发效率将会大大提升。

Linux的命令很多，应该说是非常多，说句实话，下方这些命令行，我也有一半是没记住的，但是这并不妨碍我学习使用Linux进行开发。

Linux 命令大全 | 菜鸟教程

这里很多小伙伴会有一个思维误区，认为学习Linux常用命令，就是要把所有的命令都背下来，其实是不需要的，我们只需要了解常用的十来个指令，其它的指令，在需要用到时，使用AI工具查询即可，换句话说，所有的命令都不需要去背，在你用得多后自然就会记住，记不住的查询下即可。

下面我们来了解下最常用的几个命令，如何打开命令行交互窗口呢？可以按快捷键Ctrl+Alt+T,或者左下角软件中搜索Terminal即可

接下来我们就来看几个常见的命令吧：

ls（英文全拼：list files）: 列出目录及文件名

Linux 文件权限分为 3 类用户，

用户类型 说明
u (user) 文件所有者
g (group) 所属用户组
o (others) 其他用户

chmod （Change Mode）用于修改文件或目录的权限

测试脚本，创建test.sh，仅用于打印日志，验证权限问题，无其它功能

指令格式

3 种权限

权限 符号 数字 说明
读 (Read) r 4 允许读取文件内容 / 列出目录内容
写 (Write) w 2 允许修改文件 / 在目录中创建/删除文件
执行 (Execute) x 1 允许执行文件 / 进入目录

例子

mkdir（英文全拼：make directory）：创建一个新的目录

命令 作用
mkdir dir 创建单个目录
mkdir -p a/b/c 递归创建多级目录

文本编辑vi

其实工作中使用vi文本编辑器很少了，有UI的系统，我们直接用gedit，没有的我们一般使用ssh，在window访问，但是，我们也稍微了解下，知道有这么一个东西即可。

  1. 启动 vi ：

vi filename

  1. 退出 vi ：
    1. 输入 :q 退出（如果文件未修改）。
    2. 输入 :q! 强制退出，不保存更改。
    3. 输入 :wq 保存并退出。

模式切换

vi 有两种主要模式：插入模式和命令模式。

  1. 插入模式 ：
    1. 命令模式按 i 进入插入模式，在当前光标位置插入文本。
  2. 命令模式 ：
    1. 插入模式按ESC可返回命令模式，输入命令后按 Enter 执行。

示例

  1. 打开文件并进行编辑 ：
  2. vi example.txt
    1. 按 i 进入插入模式，编辑文件。
    2. 按 Esc 返回正常模式。
    3. 输入 :wq 保存文件。
    4. 输入 :q 退出 Vi。

cd（英文全拼：change directory）：切换目录

命令 作用
cd 回到家目录
cd ~ 回到家目录
cd /path/to/dir 进入绝对路径目录
cd .. 返回上级目录
cd - 返回上一次目录

pwd（英文全拼：print work directory）：显示目前的目录

cp（英文全拼：copy file）: 复制文件或目录

rm（英文全拼：remove）: 删除文件或目录

mv（英文全拼：move file）: 移动文件与目录，或修改文件与目录的名称

tar (Tape Archive) 是 Linux 中最常用的归档工具，用于将多个文件/目录打包成单个文件（支持压缩）。

操作 命令
打包 tar -cvf archive.tar files/
gzip压缩 tar -czvf archive.tar.gz files/
解包 tar -xvf archive.tar
解压gzip tar -xzvf archive.tar.gz

主操作模式

选项 说明
-c 创建新归档
-x 解压归档

辅助选项

选项 说明
-v 显示详细过程
-f 指定归档文件名（必须放在最后）
-z 使用gzip压缩/解压（.tar.gz）
-j 使用bzip2压缩/解压（.tar.bz2）

df （Disk Filesystem）是 Linux 系统中用于 查看磁盘空间使用情况 的命令

可以显示文件系统的总容量、已用空间、可用空间及挂载点信息。

df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1       100G  5.0G   95G   5% /
tmpfs           800M     0  800M   0% /dev/shm
